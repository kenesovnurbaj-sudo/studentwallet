# StudentWallet: frontend

React + Vite. Работает вместе с backend (папка `backend/`).

## Запуск

Нужен Node.js 18 или новее. Backend должен быть запущен на `http://127.0.0.1:8000`.

```bash
cd frontend
npm install        # один раз, скачивает библиотеки
npm run dev        # запускает сайт
```

Откройте адрес из терминала, обычно http://localhost:5173.

Запросы на `/api/...` автоматически уходят на backend (настройка в `vite.config.js`).

## Структура

| Файл | Назначение |
|---|---|
| `src/api.js` | все запросы к backend, токен входа, тексты ошибок на русском |
| `src/App.jsx` | решает, что показать: вход или главный экран |
| `src/AuthPage.jsx` | вход и регистрация |
| `src/Dashboard.jsx` | главный экран, загрузка данных |
| `src/Hero.jsx` | блок «можно потратить сегодня», прогресс бюджета, форма бюджета |
| `src/ExpenseForm.jsx` | форма новой траты или дохода |
| `src/ExpenseList.jsx` | история с фильтром по категории и удалением |
| `src/format.js` | форматирование сумм, дат, склонение слова «день» |
| `src/styles.css` | все стили |

## Что реализовано

US-1, US-2 (регистрация, вход, выход), US-4 (добавление трат и доходов), US-6 (список с фильтром по категории), US-8 (задать бюджет), US-9 (остаток и дневной лимит), частично US-10 (предупреждение при 80% и 100% на экране).

Пока не реализовано: редактирование траты, свои категории, графики, цели, уведомления в базе.
